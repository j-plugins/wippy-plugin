## Rules

### Gradle build/test invocation (Metaspace OOM)
**Source**: tech-stack fact (default Gradle daemon crashed with `OutOfMemoryError: Metaspace` repeatedly)
**Rule**: Run the verify build/test gate as
`GRADLE_OPTS="-Dorg.gradle.jvmargs=-Xmx2g -XX:MaxMetaspaceSize=1g" ./gradlew <task> --no-daemon`
(e.g. `compileKotlin`, `test --tests "<pattern>"`, `buildPlugin`). The default daemon OOMs on
Metaspace on this IntelliJ Platform build. Note: `--tests` cannot be combined with non-test tasks
in one invocation (e.g. `test buildPlugin --tests ...` fails) — run them as separate invocations.

### IntelliJ plugin GUI cannot be auto-verified headlessly
**Source**: verification limitation (this is an IntelliJ Platform plugin; `runIde` is a GUI and the
IDE-introspector MCP is not connected in a headless session)
**Rule**: Do NOT claim GUI/editor behavior verified from a headless run. Verify what is automatable —
`compileKotlin` + `buildPlugin` (validates `plugin.xml`/extension registrations) + Platform tests
(`ParsingTestCase`/`LexerTestCase`; parse real fixtures such as `playground/**/*.jet` through the
ParserDefinition and assert no `PsiErrorElement`). Explicitly flag the `runIde` smoke test (icons,
highlighting, completion, optional-`<depends>` resolution) as the user's manual step.
