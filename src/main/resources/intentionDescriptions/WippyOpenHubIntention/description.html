Opens the Wippy hub page for a registry dependency.

Available on the component: value of a kind: ns.dependency entry in a Wippy registry file (_index.yaml). Invoking it opens https://hub.wippy.ai/<org>/<module> in the browser, appending ?version= when the entry pins a concrete version.

For example, on component: wippy/llm it opens https://hub.wippy.ai/wippy/llm.
